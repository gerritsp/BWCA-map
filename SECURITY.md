# Security policy

## Supported version

Security fixes are made on the current `main` branch. The public website should
be deployed from a commit that has passed the repository validation workflow.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.
Instead, use the repository's private
[security-advisory form](https://github.com/gerritsp/BWCA-map/security/advisories/new)
and include the affected page or file, steps to reproduce, and the potential
impact. Do not include real credentials, private data, or destructive proof of
concepts.

Routine map-data corrections and routing-quality reports are not security
issues and may be reported through the normal project issue process.
